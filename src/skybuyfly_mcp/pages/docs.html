SkyBuyFly

SkyBuyFly for AI assistants

SkyBuyFly compares duty-free prices for the same product across airport shops: hundreds of thousands of products at more than 80 airports. Connect it to ChatGPT, Claude, VS Code, Cursor, Gemini CLI or another MCP client, then ask what a product costs at the airports you fly through. SkyBuyFly can confirm a price live on the airport shop's own page.

MCP server URL

https://skybuyfly.pitchai.net/mcp

  • Streamable HTTP
  • No sign-in
  • Read-only tools
  • Free to use

SkyBuyFly compares, it does not sell. It cannot reserve, order or pay for anything. Links open SkyBuyFly's product and offer pages, which hand off to the airport shop's own website.

Connect your assistant

Use the URL above wherever your client asks for a remote MCP server or connector. No authentication is needed.

ChatGPT
  1. In ChatGPT on the web, open chatgpt.com/plugins, select the plus button and Add custom MCP server.
  2. Enter the name SkyBuyFly and, under Connection, the server URL:https://skybuyfly.pitchai.net/mcp
  3. Choose No authentication, review the risk warning and select I understand and want to continue, then select Create as a plugin.
  4. Install it from your plugins, then type @ in the prompt box and select SkyBuyFly.

OpenAI's help centre lists custom MCP servers on ChatGPT on the web for Business and Enterprise/Edu, and for Pro with read and fetch permissions. On Business, an admin or owner adds them.

Claude (claude.ai and Claude Desktop)
  1. Go to Customize > Connectors, select + Add and then Add custom connector.
  2. Enter the name SkyBuyFly and the remote MCP server URL below, then select Continue.https://skybuyfly.pitchai.net/mcp
  3. Choose No sign in and select Add.
  4. Turn it on in a chat with + > Connectors.

Custom connectors are available on every Claude plan; on the Free plan you can add one. On Team and Enterprise plans, an Owner adds it under Organization settings > Connectors (Add, then Custom > Web), and members then select Connect under Customize > Connectors.

Claude Code 
claude mcp add --transport http skybuyfly https://skybuyfly.pitchai.net/mcp

This adds the server to the current project. Add --scope user before the name to use it in all your projects.

VS Code
Install in VS Code

VS Code shows the server for review before you install it. Or run MCP: Add Server from the Command Palette, choose HTTP and enter the server URL. To use a configuration file, add this to ~/.copilot/mcp-config.json:

{
  "mcpServers": {
    "skybuyfly": {
      "type": "http",
      "url": "https://skybuyfly.pitchai.net/mcp"
    }
  }
}

Tools

All tools are read-only. Every tool that shows prices takes an optional currency (an ISO 4217 code such as EUR; the default is USD).

SkyBuyFly MCP tools and what they return
ToolWhat it doesMain inputs
search_productsSearches the catalogue and returns one card per product with its price at every airport shop that sells it, cheapest first.search text; optional airport IATA codes (up to 10); up to 20 results; next-page cursor
get_productOne product's description, size, every stored airport offer (the shop's own price, the converted price, when it was observed) and similar products.product ID
get_live_pricesConfirms the product's price now on each airport shop's page. Every offer is marked live-confirmed or stored with its date; the cheapest is highlighted.product ID; seconds to wait (5 to 20, default 12)
get_price_historyThe product's observed prices per airport over time, with the lowest and latest price.product ID
lookup_barcodeFinds the product that carries a barcode and its airport prices. An empty list means no shop SkyBuyFly compares sells it.EAN-8, UPC-A, EAN-13 or GTIN-14 digits
list_airportsThe airports SkyBuyFly compares, with IATA code, name, city and the shops' store domains.optional text filter, such as a city
get_featured_productsFeatured products with their airport prices, and the most popular categories. Not personalised.none
list_currenciesThe currencies SkyBuyFly can show prices in.none
get_catalogue_statsThe number of products and airports and when the figures were generated.none

In ChatGPT and Claude, results are shown as product cards with a price per airport, marked live-confirmed or stored.

  • Show the price history of Dior Sauvage Eau de Parfum 100 ml at airport duty-free shops.
  • Which airport shops sell the product with barcode 3145891165203?
  • Compare Lagavulin 16 at Copenhagen and Düsseldorf duty free in euros.
  • Which London airports does SkyBuyFly compare?

How the prices work

  • Stored prices. SkyBuyFly collects prices from the airport shops' own websites, from shops such as Heinemann, Avolta and Dubai Duty Free. Every price carries the date it was observed, and a stored price can be out of date.
  • Live prices. A live check makes SkyBuyFly open each airport shop's product page and confirm the current price. Prices the shop does not confirm in time are returned as stored prices with their date.
  • Currencies. Each offer has the shop's own price; prices in another currency are converted.
  • Coverage. Not every airport or shop is covered, and some products are listed at one airport only. Tobacco and nicotine products are not included.

Limits

  • A live check usually takes 5 to 15 seconds; the tool waits at most 20 seconds (12 by default).
  • Each requesting address can make up to 300 tool calls per minute (all users of one AI service often share its address), and all users together up to 1,200. When a limit is reached, the tool answers with the number of seconds to wait.
  • Live checks are limited to 20 new checks per minute and 4 at a time across all users, within the limits of SkyBuyFly's live price service. The live result for the same product and currency is reused for 60 seconds. When live checks are busy, the tool says so and the stored prices are still available.
  • Search results are kept for a minute, product details for two minutes and price history, airports and currencies for ten minutes.

Privacy, terms and support

The server needs no account and sets no cookies. It receives only the inputs of a tool call, such as search text or a barcode, never your conversation. Details are in the privacy notice for SkyBuyFly in AI assistants.
